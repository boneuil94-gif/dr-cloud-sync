# Position TVA

La TVA collectée n'est disponible que lorsque TTC et HT sont complets dans le Sales Ledger (`TTC - HT`). Une vente fiscalement incomplète rend la métrique indisponible. La TVA déductible requiert une facture fournisseur fiable: un débit ou une commande ne suffit jamais. La position sera `collectée - déductible` seulement si les deux côtés sont disponibles et restera étiquetée **ESTIMATION**, jamais déclaration.
